═══════════════════════════════════════════════════════════════
PASO 1: Configurar Git
═══════════════════════════════════════════════════════════════

cd ~/Documents/GitHub/present

git init
git config user.name "Tu Nombre"
git config user.email "tu@email.com"
git remote add origin https://github.com/JLMirallesB/present.git

═══════════════════════════════════════════════════════════════
PASO 2: Hacer commit y push
═══════════════════════════════════════════════════════════════

git add .
git commit -m "Enhanced fork with display names, multiple lists, and improved navigation"
git branch -M main
git push -u origin main

═══════════════════════════════════════════════════════════════
PASO 3: Crear release (opción A - Con gh CLI)
═══════════════════════════════════════════════════════════════

git tag -a v1.0 -m "Release v1.0"
git push origin v1.0

gh release create v1.0 \
  --title "Present 1.0 - Enhanced Fork" \
  --notes-file RELEASE_NOTES.md \
  Present-1.0.dmg

═══════════════════════════════════════════════════════════════
PASO 3B: Crear release (opción B - Manualmente en GitHub)
═══════════════════════════════════════════════════════════════

1. Ve a: https://github.com/JLMirallesB/present
2. Click en "Releases" (lado derecho)
3. Click en "Create a new release"
4. Tag: v1.0
5. Title: Present 1.0 - Enhanced Fork
6. Description: (pega contenido de RELEASE_NOTES.md)
7. Adjunta: Present-1.0.dmg
8. Click "Publish release"

¿TE FALTA ALGO?
═══════════════════════════════════════════════════════════════

❌ No tengo GitHub configurado
   → Primero crea una cuenta en github.com
   → Crea un repositorio llamado "present"
   → Usa los comandos arriba

❌ No tengo gh CLI instalado
   → Usa la opción B (manual en GitHub)
   → O instala: brew install gh

❌ El archivo .dmg no está aquí
   → Está en: ~/Documents/GitHub/present/Present-1.0.dmg
   → Check con: ls -lh Present-1.0.dmg
